# LATAM Banana Fruit Characteristics Clock

An interactive 52-week climate calendar for tropical banana production across
eight Latin American export regions.

## What it does
- Displays a radial "clock" chart per region mapping the full production year
- Each arc represents a climatic window (Cold/Warm/Hot × Dry/Rainy)
- Hovering an arc shows expected fruit condition, agronomic notes,
  and pest & disease pressure for that period
- A live indicator highlights the current production week automatically

## Regions covered
Costa Rica · Colombia · Ecuador · Guatemala · Honduras ·
Panama · Dominican Republic · Belize *(adjust según los reales)*

## How to use
Open `index.html` in any modern browser — no installation required.
Single self-contained file, no external dependencies beyond Google Fonts.
